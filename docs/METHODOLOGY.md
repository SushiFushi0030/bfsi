# BFSI v0.1 计算与解释

本次工程迁移保留原公式源文件的字节内容，未重新标定参数。统计单位为不同 Comment ID，完全相同的语义记录只计一次；同ID冲突直接失败，禁止混合视频。Observation用于记录评论在不同接口/位置出现的次数，不是权重。

设总评论数为N，看多B、看空S、混合M：

| 指标 | 公式 | 无信号约定 |
| --- | --- | --- |
| 方向分数 | `(B-S)/(B+S+M)` | 分母0 → 0 |
| BFSI | `50+50×方向分数` | 数值占位50，`no_directional_signal=true`；界面显示破折号 |
| 方向覆盖率 | `(B+S+M)/N×100%` | 没有方向评论 → 0% |
| 多空分歧 | `(1-abs(B-S)/(B+S))×100` | B+S=0 → 0并设置`no_bullish_bearish_signal` |

`mixed`参与BFSI分母，分子贡献0，不参与多空分歧计算。`neutral/unclear/not_applicable`不参与方向分母。主指数不过滤财经相关性，也不按点赞、时间、模型置信度加权。

中间计算使用`Fraction`；显示采用十进制`ROUND_HALF_UP`，BFSI与百分比保留1位，分歧显示整数。示例：B=2、S=1、M=1、N=5，则BFSI=62.5、覆盖率80%、分歧约66.7，显示67。

## 辅助统计

财经相关性、动作意图、创作者态度、讽刺和置信度使用冻结枚举。情绪为多标签，同评论的同标签只计一次，各类别总数可能超过N。辅助比率分母均为全部不同评论，不能和方向样本分母混用。

对象首先应用仅包含通用宏观词的别名规则，再按评论去重计算提及数。对象指数展示阈值为至少5条不同评论，立场来自评论整体标签，因此只能解释为共现近似。未提供按对象单独识别的立场。

代表评论按确定性规则从高/中置信标签中选择，优先类别为看多3、看空3、混合2、求建议2、幽默2，跨组去重；分享海报最多放5条。样本不足时显示空，不补造内容。它们不构成随机抽样或人工审核证据。

合成演示的标签由脚本明确构造，不代表模型准确率。项目尚无独立人工金标准、误差区间、跨视频时序校准或市场预测效度评估。
